"Optimal Investment into Carbon Abatement Technologies under Uncertainty Aversion: Subsidies versus Taxes"
supervised by Univ. Prof. Dr. Rüdiger Frey.

"numerical_experiment.R" contains the code relevant for generating the plots in chapter "Numerical Results",
while "eurostat_carbon_emission_by_sectors.R" generates the carbon emissions by sector plot in the
introduction chapter.
